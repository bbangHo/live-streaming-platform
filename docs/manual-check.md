# manual-check.md — 사람이 직접 찍는 수동 확인

브라우저 화면공유·소리처럼 자동 테스트로 못 하는 것만 모았다. 결과를 각 줄 `[ ]`에 ✅/❌로 남긴다. 상세 설명은 [README](../README.md) "기능 확인".

## 0. 전제
- 스택 기동: 레포 루트에서 `docker compose up -d --build` (뜰 때까지 1~2분).
- 접속: http://localhost:8000 · API http://localhost:8080 · 테스트 계정 `demo1`/`demo1234`, `demo2`/`demo1234`.
- 송출은 **Chrome/Edge 최신**. 소리 나는 탭(예: 유튜브) 하나 미리 띄워 둔다.

## 1. 필수 — PC 송출 → 시청 → 종료 (핵심, 아직 아무도 안 함)
- [ ] `demo1` 로그인 → **방송 만들기**(제목·설명) → 상세로 이동
- [ ] **PC 화면 송출 → 방송 시작** → 공유창에서 **소리 나는 탭 선택 + 「오디오 공유」 켜기** → 마이크 허용
- [ ] 합격: 로그에 `화면 소리 1개, 마이크 1개`, 2초 내 상태 **방송 중**
- [ ] 다른 창(시크릿/비로그인)으로 http://localhost:8000 → **방송 중** → 방송 클릭 → 음소거 해제
- [ ] 합격: 1~4초 지연으로 **화면 + 탭소리 + 마이크소리** 다 나옴
- [ ] **방송 종료** → 상태 **종료**, 시청 화면 「종료된 방송입니다」

## 2. 필수 — 인가 (서버측)
- [ ] 로그아웃 또는 `demo2`로 같은 방송 열기 → 관리 영역 없음, 송출 페이지 「소유자만 송출」
- [ ] (선택) API 확인: README "인증·인가 확인(API)" 블록 → 비로그인 401 / 타인 403

## 3. 필수 — 끊김 유예 & 영구저장
- [ ] 송출 중 송출 페이지 닫기/「공유 중지」 → **30초간 방송 중 유지**, 다시 시작하면 이어짐 / 30초 넘기면 자동 종료
- [ ] `docker compose restart` 후에도 방송이 그대로 조회됨

## 4. 선택(가산점) — 되면 찍기
- [ ] 댓글: 비로그인 읽기, 로그인 쓰기, 내 댓글만 수정·삭제
- [ ] 녹화: 종료 몇 초 뒤 **다시보기**에 생김 → 재생됨
- [ ] 도네이션: `demo2`→`demo1` 방송 **후원** → 테스트 결제창 카드 `4242 4242 4242 4242` → 합계 반영. **결과창 새로고침해도 합계 그대로**(중복적립 방지)

## 5. 실기기 — 여유 될 때 (현재 미확인)
- [ ] 모바일 송출: `.env`에 `DOMAIN`·`PUBLIC_HOST`=PC LAN IP → `docker compose --profile https up -d` → 폰에서 `https://<LAN IP>/` 로그인 → 모바일 카메라 송출 (사설 인증서 경고 수락, 전/후면 전환)
- [ ] 모바일 시청: 폰에서 `http://<LAN IP>:8000/` (방화벽 8000 허용 필요할 수 있음)
- [ ] Safari(iOS) 재생
