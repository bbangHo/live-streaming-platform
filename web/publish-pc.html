PC 송출 · 화면 + 탭/시스템 소리 + 마이크 · 모바일 카메라 송출로

송출 안 함 시청 화면 열기

송출 방법 · 로그
  1. 「방송 시작」 → 공유 창에서 탭(또는 창·전체 화면)을 고르고 「오디오 공유」를 켭니다. 탭 소리는 Chrome·Edge에서만 됩니다.
  2. 마이크 권한을 허용하면 화면 소리와 마이크가 한 소리로 섞여 나갑니다.
  3. 송출이 연결되면 몇 초 안에 상태가 「방송 중」으로 바뀝니다.
  4. 「방송 종료」를 누르면 방송이 끝납니다. 창을 닫거나 「공유 중지」를 눌렀다면 30초 안에 다시 시작하면 방송이 이어집니다.
